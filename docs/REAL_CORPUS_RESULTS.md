# 真实语料结果与复现边界

本页记录 2026-10-27 在 H20 GPU0 上完成的真实语料实验。它区分三类证据：

1. **历史公开工作点**：仓库原有 Stage-1/Stage-2 结果；
2. **真实语料扩展**：同一冻结模型、同一候选池上的新增消融；
3. **工程基准**：KV-cache 的延迟、显存和数值一致性。

合成 fixtures 只验证代码路径，不作为准确率证据。

## 数据与协议

- 测试语料：2031 条话语、3244 个关键词 occurrence、293 个词。
- 声学特征：冻结 Step-Audio-2-mini 的 `llm2` 隐状态，80 ms/帧，3584 维。
- Stage-1 候选池：Top-20；Stage-2 重排权重：`Z_acoustic + 4.0 Z_LM`。
- occurrence Top-1：每个 occurrence 等权；词级 Top-1：先按词平均，再跨词平均。
- 交叉验证折按 utterance 或 `rec_sXX` session/speaker 分组；超参数只在训练折选择。
- 所有 GPU 推理固定在 `cuda:0`，GPU1 未使用。

## Stage 1：定位与校准

### 主要消融

| 配置 | occurrence Top-1 | 词级 Top-1 | Top-20 池召回 |
|---|---:|---:|---:|
| k=5 均值模板（历史基线复算） | 0.4371 | 0.4821 | 0.9251 |
| k=8 均值模板 | 0.4732 | 0.5523 | 0.9343 |
| k=8 + enrollment mean centering | **0.4741** | 0.5451 | **0.9467** |
| k=8 + ABTT | 0.3952 | 0.4506 | 0.8634 |
| k=8 + PCA whitening | 0.4319 | 0.4908 | 0.9097 |
| duration-adaptive window | 0.4658 | 0.5412 | 0.9340 |
| 2-means 多原型 + 多尺度 | 0.4498 | 0.5142 | 0.9168 |

结论：加宽到 8 帧、再扣 enrollment 全局均值，是这组候选中唯一稳定提高池召回的方向；
ABTT/PCA 白化、2/3-means 子原型和“保留全部注册样本”均未改善真实语料。

### Speaker-disjoint 嵌套 CV

候选集固定为 `{k5,k8} x {none,center}`。每折只在训练 session 上按 occurrence Top-1
（并列时看 Top-20）选配置，再评估留出 session。

| 指标 | k5 基线 | 嵌套选择 |
|---|---:|---:|
| occurrence Top-1 | 0.4371 | **0.4741** |
| 词级 Top-1 | 0.4821 | **0.5451** |
| Top-20 池召回 | 0.9251 | **0.9467** |

- 五折全部选择 `k8 + center`，per-utterance bootstrap 增益 **+3.699 点**，
  95% CI **[+2.796, +4.607]**。
- utterance-grouped 五折为 **+3.514 点**，CI **[+2.624, +4.419]**。
- 同一报告中的自适应窗平均覆盖率为 0.7950，而 k5 为 0.6761；但自适应窗没有超过 k8+center。
- `grow_span` 对 k5 的池召回为 0.9239，与固定窗 0.9242 基本持平，没有可测收益。

### 层融合

在 k=8 + center 下，`llm2` 的池召回为 0.9467；`llm1` 为 0.9337；
`llm1:0.5 + llm2:0.5` 为 0.9414；`llm2:0.7 + llm6:0.3` 为 0.9396。
真实语料上没有观察到晚融合收益，因此默认仍使用 `llm2`。

层 0 是 24 个 occurrence 探针的赢家，类间与类内比为 0.4828，Top-20 召回为 1.0000；
`llm2` 分别为 0.5471 和 0.9583。全量语料目前只有 `llm1/llm2/llm6` 的层视图，
没有层 0 的 2031 句特征，因此层 0 只能标为“下一轮首选实验”，不能写成全量最优。

## 融合权重：`1.5` 是继承值，不是最优值

`1.5` 来自更早实验，在 v95 中没有重新选择。它乘在语言模型项上，声学项系数固定为 1。
在同一复算 runner 上重新扫描，C 臂的权重曲线为：

| lambda_LM | C occurrence Top-1 | C 词级 Top-1 | C + phonetic occurrence | C + phonetic 词级 |
|---:|---:|---:|---:|---:|
| 1.5 | 0.5311 | 0.6182 | 0.5358 | 0.6286 |
| 2.0 | 0.5367 | 0.6218 | 0.5419 | 0.6358 |
| 3.0 | 0.5413 | 0.6289 | 0.5478 | 0.6456 |
| 4.0 | 0.5416 | 0.6258 | **0.5496** | **0.6449** |
| 4.75 | 0.5432 | 0.6257 | 0.5499 | 0.6441 |

- utterance-grouped 嵌套 CV 的五折选择为 `4.75, 4.0, 4.75, 4.25, 4.75`；
  speaker-grouped 为 `4.75, 4.75, 4.0, 5.5, 4.0`。两种分组都落在 4.0 到 4.75 的平台。
- 嵌套选择的 occurrence Top-1 为 0.545006，旧 `1.5` 为 0.536991，
  增益 **+0.801 点**，95% CI **[+0.250, +1.370]**。
- 同一复算 runner 上，C 从 `1.5` 的 0.5311 升到 `4.0` 的 0.5416，
  增益 **+1.048 点**，95% CI **[+0.471, +1.625]**。
- 在 `4.0` 下再加入音素软吸附，相对旧 C@1.5 的总增益为 **+1.850 点**，
  95% CI **[+1.183, +2.546]**，绝对值为 0.5496 / 0.6449。
- 权重升高后朴素切分 P 从 0.4538 退到 0.4112，C 从 0.5311 升到 0.5416。
  语义项越重要，错误前缀的代价越大，网格吸附越不能被省略。

仓库默认采用更保守的 `4.0`。`4.75` 的 occurrence 点估计只高 0.03 点，词级略低，
不足以支持把峰值写成唯一最优点。

为确认声学项没有被权重扫描“挤掉”，在同一候选池上固定 C 臂并改变
`lambda_LM`：`0` 只保留声学项，occurrence Top-1 为 0.4399；`4.0` 为 0.5416；
`100` 近似 LM-only，回落到 0.5324。声学项仍然贡献排序信息，`1.5` 的问题
不是“声学权重太强”，而是语言模型项被压得太低。

## Stage 2：异构对齐、音素吸附与 PMI

全部 2031 句、3244 个 occurrence 使用同一 Top-20 候选池，下表统一在 `lambda_LM=4.0` 下复算。

| 分支，`lambda_LM=4.0` | occurrence Top-1 | 词级 Top-1 | 相对复算 C |
|---|---:|---:|---:|
| P，朴素切分 | 0.4112 | 0.4308 | -13.04 点 |
| C，复算并启用 KV cache | 0.5416 | 0.6258 | 0 |
| **C + phonetic soft snap** | **0.5496** | **0.6449** | **+0.801 点** |
| C + Top-2 NMS starts | 0.5484 | 0.6383 | +0.678 点 |
| C + PMI, gamma=0.25 | 0.5438 | 0.6278 | +0.216 点 |
| 历史公开 C，`lambda_LM=1.5` | 0.5370 | 0.6266 | +0.59 点，runner 差异 |

配对 bootstrap（按话语重采样）：

- phonetic 相对复算 C：**+0.801 点**，95% CI **[+0.345, +1.262]**。
- Top-2 NMS 相对复算 C：+0.678 点，95% CI **[+0.187, +1.175]**，转为显著，但仍低于音素吸附。
- PMI gamma=0.25 相对复算 C：+0.216 点，没有形成稳定增益。
- phonetic 相对旧 `C@1.5`：+1.850 点，95% CI **[+1.183, +2.546]**。

解读：

- 音素软吸附是 `4.0` 下同时提高 occurrence 和词级指标、且置信区间不跨零的 Stage-2 扩展；
- 固定 gamma 的 PMI 在真实语料上失败，不能作为默认校准；
- `C` 的重算与历史值差 0.59 occurrence 点 / 0.84 词级点。缓存不是原因：200 句全序列
  与缓存的三路审计已对齐（见下）；该差距应标为“历史 runner 复现差”，而不是新收益。
- 两个分支的前缀自身首字泄漏率均为 0.0129；音素吸附改善的是吸附命中与排序，
  不是该二值泄漏率。

### KV-cache 一致性

在 200 条留出话语、20 候选、fp16、GPU0 上比较 full-sequence 与 cached：

| 分支 | 最大绝对差 | 句中最大差中位数 | Spearman 最小 | Top-1 同号 |
|---|---:|---:|---:|---:|
| P | 0.0469 nats | 0.0189 | 0.9970 | 200/200 |
| C | 0.0391 nats | 0.0172 | 0.9970 | 199/200 |
| C + phonetic | 0.0391 nats | 0.0174 | 0.9970 | 199/200 |
| C + Top-2 | 0.0391 nats | 0.0164 | 0.9985 | 199/200 |

四个分支在 200 句子集上的 occurrence Top-1 与词级 Top-1 **逐项相同**。

修复点：full-sequence 路径此前对不等长前缀做左填充但没有显式给出由 attention mask
推导的 `position_ids`，同时只按候选 token 长度分组。现在按“前缀 token 长度 x 候选
token 长度”分组，并显式传入绝对位置；修复前最大差可达 13.7 nats，修复后小于 0.05 nats。

## 时序形状：诊断信号与端到端阴性结论

### Shape-only

| 算子 | occurrence Top-1 | 词级 Top-1 |
|---|---:|---:|

| PCA 线性 | 0.1347 | 0.1169 |
| PCA shift-invariant | 0.0981 | 0.1110 |
| **subsequence DTW** | **0.3633** | **0.4199** |

### Entropy-gated fusion

| 基线 | 门控臂 | 分组 | 增益 | 95% CI |
|---|---|---|---:|---:|
| LM-only | DTW | utterance 5-fold | **+0.865 点** | [+0.266, +1.500] |
| LM-only | DTW | speaker 5-fold | **+0.832 点** | [+0.264, +1.449] |
| `acoustic + 1.5 LM` | 全形状臂 | utterance 5-fold | **-0.333 点** | [-0.605, -0.098] |
| `acoustic + 1.5 LM` | 全形状臂 | speaker 5-fold | **-0.399 点** | [-0.741, -0.068] |
| `acoustic + 4.0 LM` | 全形状臂 | utterance 5-fold | **-0.033 点** | [-0.332, +0.268] |
| `acoustic + 4.0 LM` | 全形状臂 | speaker 5-fold | **-0.233 点** | [-0.533, +0.065] |

结论：DTW 在“语言模型单独犹豫”的诊断场景中确实提供互补信号，但该收益不能迁移到
可部署的声学+LM 融合基线。权重改到 4.0 后，utterance 五折回到零附近，
speaker 五折为 -0.233 点且区间跨零；两种分组都没有正收益；
因此默认系统继续关闭 shape tie-break。

## KV-cache 工程基准

H20、20 候选、共享前缀、fp16、五次 warm run 的中位数：

复现入口：`scripts/benchmark_kv_cache.py`。

| 载波音频 | full | cached | 加速 | 额外峰值显存 |
|---|---:|---:|---:|---:|
| 1.0 s | 0.283 s | 0.160 s | 1.77x | 174 -> 154 MB |
| 3.6 s | 0.239 s | 0.183 s | 1.30x | 127 -> 123 MB |
| 6.4 s | 0.301 s | 0.141 s | 2.14x | 192 -> 163 MB |

这些结果不支持“5–10x”或“显存下降 80%+”的宣传。收益有限的原因是原路径已经按候选
token 长度批处理，且候选只有 1–4 个 token；缓存主要有利于长共享前缀和更大候选池。

## 当前发表口径

可以主张：

- 在 speaker-disjoint 嵌套 CV 中，`k8 + center` 相对历史 k5 基线提高 **3.70 点**
  occurrence Top-1 和 **2.16 点**池召回；
- `lambda_LM=4.0` 相对历史 `1.5` 的嵌套 CV 增益为 **+0.80 点**，稳定平台为 4.0 到 4.75；
- 音素软吸附在 `4.0` 下相对复算 C 有 **+0.80 点**的统计支持增益；
- 层 0 在 24 个 occurrence 的探针上取得最低类间与类内比和全召回；
- DTW 形状信号在 LM-only 诊断基线上存在稳定互补性；
- KV cache 在保持一致排名的同时提供 **1.30–2.14x** 实测加速。

不应主张：

- 层 0 已经通过全量评测，或已经优于 `llm2` 的全量池召回；
- PMI、ABTT/whitening、多原型或现有层融合在真实语料上带来净收益；
- Top-2 NMS 优于音素软吸附；
- DTW 门控在可部署融合基线上有效；
- KV cache 有 5–10x 加速或 80% 显存下降。

剩余外推风险：当前只有一个 2031 句真实语料；speaker 分组使用 `rec_sXX` 规则，
正式论文前应使用官方 speaker ID 做 speaker-disjoint 划分，并补充第二套独立语料。
